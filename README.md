## Что здесь

Проект берёт из учебной базы ПРАЙМ выгрузку по закреплённому за мной участку:
попытки списания платы за подписку через электронный кошелёк за первый квартал
2026 года, выборка из 1000 подписок. По ней считается сводка: сколько списаний
прошло и не прошло, выручка, распределение по дням недели, пиковые дни и то,
как набиралась сумма внутри квартала. Расчёты и выводы — в `notebooks/hw1.ipynb`.

На данный момент проект берет из базы ПРАЙМ, выгрузку моего участка, а именно попытки списания платы за подписку через электронный кошелёк за первый квартал
2026 года. Работает с выборкой 1000. Из этой выборки удалось поулчить выводы об успешных и не успешных списаниях, а так же выручку, распределение по дням недели, пиковые дни квартала и построить гипотезу о тенденции роста выручки.  Все расчеты доступны к просмотру в файле hw1.ipynb

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:1exa4ka/-.git
cd ./-
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
